# Troubleshooting Common Problems

| Problem                                                                                           | Solution                                                                                                                                                                                                                       |
|---------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SSL or certificate errors when connecting to the gateway                                          | Server certificate is untrusted or self-signed. Use `ignore-server-cert` parameter (or set in the advanced UI settings under "Certificates" section) to disable all HTTPS certificate checks (not recommended).                |
| Unable to reach remote sites by their fully qualified names                                       | VPN server does not return back the proper search domains. Use the `search-domains` option to specify DNS domains manually.                                                                                                    |
| VPN tunnel is unstable and disconnects quickly                                                    | Set the `mtu` option to a lower value like 1280.                                                                                                                                                                               |
| IPsec over TCPT connects, but no traffic passes and keepalive fails                               | The gateway may be behind NAT and ignore ESP and keepalive packets addressed to its public address. Set `gateway-internal-ip` to its internal address, which the Windows client logs as `gw_internal_ipaddr` in trac.log.      |
| IPsec over UDP connects, but no traffic passes and the tunnel drops after about 20 seconds        | A gateway behind NAT may not accept ESP over UDP although its NAT-T port answers, so `transport-type=auto` still picks UDP. Set `transport-type=tcpt`, and `gateway-internal-ip` as described above.                           |
| Connect attempt silently times out after ~10 s with `client error (Connect): operation timed out` | Some Check Point gateways stop responding to TLS 1.3 ClientHellos issued by recent OpenSSL releases (3.5+). The default `tls-version-max=1.2` works around this. If a gateway requires TLS 1.3, set `tls-version-max=default`. |
| Not all remote sites are reachable and not all routes are advertised                              | A policy-based access is required via [machine certificate authentication](certificates.md).                                                                                                                                   |
